# 성경 타임라인 (bible-is-fact)

구약과 신약의 사건·인물을 연대순으로 살펴보는 인터랙티브 웹 타임라인입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작하는 정적 웹사이트입니다. [Vercel](https://vercel.com)로 배포합니다 (아래 "배포" 참고).

## 구성

구약과 신약을 **하나의 타임라인**(원역사 ~ AD 100)으로 보여 줍니다. 여러 줄(레인)로 같은 시기를 나란히 비교합니다.

- 줄: 시대 / 주요 사건 / 인물 / 왕·통치자 / 선지자 / 예수 그리스도 / 예수의 기적 / 사도·초대교회 / 바울 / 신약 기록 / 주변 세계·역사
- **예수의 기적·공생애 (접기/펼치기)**: 사복음서의 기적 35가지와 공생애 보충 사역 9가지(니고데모, 사마리아 여인, 열두 제자 선택·파송, 최후의 만찬 등)는
  기본으로 접혀 있습니다. 가로 보기에서는 줄 이름 아래 `▸ 펼치기` 버튼이나 요약 막대를, 세로 보기에서는 예수 그리스도 시대 첫 구간의 버튼을 누르면 펼쳐집니다.
  검색·이전/다음으로 접힌 항목을 고르면 자동으로 펼쳐집니다. (기적의 시기는 복음서 조화 순서에 따른 대략적 위치입니다)
- 맨 앞 빗금 구간: 연대를 특정할 수 없는 원역사 (창 1–11장), 연도는 `?`로 표시
- 상단 `전체 / 구약 / 신약` 버튼: 전체 기간, 구약 시대(~BC 4), 신약 시대(BC 40~AD 105)로 바로 이동·확대
- 데이터는 [`js/data.js`](js/data.js)에서 구약(`ot`)·신약(`nt`) 부분으로 나눠 관리하고, 화면에서 합칩니다.
  신약의 로마 황제·유대 통치자·유대·로마 사건 줄은 각각 '주변 세계·역사', '왕·통치자', '주변 세계·역사' 줄로 옮겨지며 원래 색을 유지합니다.

## 모바일 (세로 보기)

화면 폭이 좁으면(760px 이하) **세로 보기**가 기본입니다. 위에서 아래로 스크롤하며 시간순으로 봅니다.

- 구간 제목이 위에 고정됩니다
- 구약 부분은 시대별, 신약 부분(예수 그리스도 시대·사도 시대)은 10년 단위로 묶이며, 신약 구간 제목 옆에는 그 10년 동안 다스린 로마 황제·유대 통치자가 함께 나옵니다
- 항목을 누르면 아래에서 설명 패널이 올라오고, 누른 항목은 패널에 가리지 않게 위로 올라갑니다
- 상단의 `가로 보기` / `세로 보기` 버튼으로 언제든 전환할 수 있고, 선택은 그 브라우저에 기억됩니다 (데스크톱에서도 사용 가능)

## 사용법

| 동작 | 방법 |
| --- | --- |
| 이동 | 마우스 드래그, 스크롤, 터치 스와이프 |
| 확대·축소 | `Ctrl`(⌘)+휠, 트랙패드 핀치, 두 손가락 핀치, `+` / `-` 키, 상단 버튼 |
| 항목 보기 | 클릭 → 오른쪽(모바일은 아래) 패널에 설명·성경 구절·**같은 시기** 항목 목록 |
| 같은 시기 | 항목을 선택하면 세로 기준선이 생기고 같은 시기 항목만 강조됨 |

| 검색 | 상단 검색창 (`/` 키), `Enter`로 결과 사이 이동 |

## 데이터 수정

모든 내용은 [`js/data.js`](js/data.js)에 있습니다.

```js
{ id: "exodus", lane: "event", start: -1446, title: "열 재앙과 출애굽", ref: "출 7–14장", desc: "..." }
{ id: "journey1", lane: "paul", start: 47, end: 48.5, approx: true, title: "1차 전도여행", ref: "행 13–14장", desc: "..." }
```

- `start` / `end`: 연도 (음수 = 기원전). `end`가 있으면 기간 막대, 없으면 점으로 표시
- `approx: true`: 추정 연대 (속이 빈 점, 점선 막대, "약" 표시)
- `lane`: 표시할 줄 (각 타임라인의 `lanes` 참고)
- `fold: "jesus"`: 접기/펼치기 묶음에 넣을 항목
- 구약의 `periods`는 '시대' 줄, `prologue`는 연대 미상 구간에 순서대로 놓입니다

연대는 보수적 전통 연대(출애굽 BC 1446, 왕상 6:1 기준)를 따르며, 학자에 따라 차이가 있습니다.

## 사실 확인 표시 (출처 포함)

항목을 누르면 상세 패널에 아래 세 가지가 구분되어 나오며, 모든 내용에 출처 링크가 붙습니다.

| 표시 | 파일 | 의미 |
| --- | --- | --- |
| 파란 `史` | [`js/history.js`](js/history.js) | 역사 기록으로 잘 알려진 사실 (로마 황제, 헤롯 왕가, 주변 제국, 유대 전쟁 등) |
| 초록 `✓` | [`js/evidence.js`](js/evidence.js) | 성경 내용을 뒷받침하는 성경 밖 자료 (고고학 발견·당대 비문·고대 문헌), 발견 전 회의적 견해가 있었으면 함께 표기 |
| 주황 `○` | [`js/research.js`](js/research.js) | 진행 중인 연구·논쟁 중인 주장 (미확인). 상태: 진행 중 / 논쟁 중 / 가설 / 해석 제기 / 미확인 |
| 빨간 `▲` | [`js/research.js`](js/research.js) | 상태에 `논란 많음`·`논문 철회`가 들어간 주장. 상세 패널에서도 빨간 상자로 따로 모아 보여 줌 |

- 논란이 많은 주장(방주 발견 주장, 예수 가족 무덤, 야고보 유골함 등)도 빼지 않고 `논란 많음`으로 표시해, 학계의 평가와 함께 적습니다.
- `research.js`의 기준 시점은 `TIMELINE_RESEARCH_DATE`(현재 2026년 10월)이며, 내용을 갱신할 때 함께 바꿉니다.
- 출처 형식: `sources: [{ label, url }]` — 위키백과 링크는 `W("문서_제목")` 도우미를 씁니다.

## 배포 (Vercel)

빌드가 없는 정적 사이트라 저장소를 연결하기만 하면 됩니다.

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인
2. **Add New… → Project** → `bible-is-fact` 저장소 **Import**
3. 설정은 기본값 그대로 둡니다
   - Framework Preset: **Other**
   - Root Directory: `./`
   - Build Command / Output Directory: 비워 둠
4. **Deploy** → `https://<프로젝트이름>.vercel.app` 주소가 생깁니다

이후 `main`에 푸시할 때마다 자동으로 다시 배포됩니다 (다른 브랜치는 미리보기 주소로 배포).
도메인을 연결하려면 Vercel 프로젝트의 **Settings → Domains**에서 추가합니다.

- [`vercel.json`](vercel.json): 깔끔한 주소(`cleanUrls`)와 기본 보안 헤더
- [`.vercelignore`](.vercelignore): 배포에서 뺄 파일 (`CLAUDE.md`, `README.md`)

## 광고 (Google AdSense)

광고 설정은 [`js/ads.js`](js/ads.js) 한 곳에 모여 있으며, 게시자 ID가 비어 있으면 광고 스크립트를 불러오지 않습니다.

- 광고 위치: 항목을 눌렀을 때 열리는 설명 패널 아래 (처음 열 때 한 번 만들고 계속 재사용 — 항목마다 새로 띄우지 않음)
- 게시자 ID를 받으면 세 곳을 맞춥니다
  1. `js/ads.js`의 `client`(게시자 ID)와 `detailSlot`(디스플레이 광고 단위 슬롯 ID)
  2. `index.html`의 `google-adsense-account` 메타 태그 (사이트 확인용, 주석 해제)
  3. 루트의 `ads.txt`: `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
- 개인정보처리방침: [`privacy.html`](privacy.html) (쿠키·광고 고지 포함, 하단에 링크)
- 타임라인 화면은 고정 레이아웃이라 애드센스 **자동 광고의 본문 내 광고**는 끄고, 필요하면 앵커 광고만 켜는 것을 권장합니다.
