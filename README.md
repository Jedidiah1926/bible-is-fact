# 성경 타임라인 (bible-is-fact)

구약과 신약의 사건·인물을 연대순으로 살펴보는 인터랙티브 웹 타임라인입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다 (GitHub Pages로 그대로 배포 가능).

## 구성

구약·신약 모두 여러 줄(레인) 타임라인으로 같은 시기를 나란히 비교합니다.

- **구약** — 시대 / 주요 사건 / 인물 / 왕·왕국 / 선지자 / 주변 세계(이집트·앗시리아·바벨론·페르시아 등)
  - 맨 앞 빗금 구간: 연대를 특정할 수 없는 원역사 (창 1–11장), 연도는 `?`로 표시
- **신약**
  - 로마 황제 / 유대 통치자 / 예수 그리스도 / 사도·초대교회 / 바울 / 신약 기록 / 유대·로마 사건

## 사용법

| 동작 | 방법 |
| --- | --- |
| 이동 | 마우스 드래그, 스크롤, 터치 스와이프 |
| 확대·축소 | `Ctrl`(⌘)+휠, 트랙패드 핀치, 두 손가락 핀치, `+` / `-` 키, 상단 버튼 |
| 항목 보기 | 클릭 → 오른쪽(모바일은 아래) 패널에 설명·성경 구절·**같은 시기** 항목 목록 |
| 같은 시기 | 항목을 선택하면 세로 기준선이 생기고 같은 시기 항목만 강조됨 |
| 이전/다음 | `←` `→` 키 또는 패널의 버튼 |
| 검색 | 상단 검색창 (`/` 키), `Enter`로 결과 사이 이동 |
| 필터 | 범례 칩을 눌러 분류/레인 숨기기·보이기 |
| 공유 | 주소가 `#nt/council` 처럼 바뀌므로 그대로 링크 공유 가능 |

## 데이터 수정

모든 내용은 [`js/data.js`](js/data.js)에 있습니다.

```js
{ id: "exodus", lane: "event", start: -1446, title: "열 재앙과 출애굽", ref: "출 7–14장", desc: "..." }
{ id: "journey1", lane: "paul", start: 47, end: 48.5, approx: true, title: "1차 전도여행", ref: "행 13–14장", desc: "..." }
```

- `start` / `end`: 연도 (음수 = 기원전). `end`가 있으면 기간 막대, 없으면 점으로 표시
- `approx: true`: 추정 연대 (속이 빈 점, 점선 막대, "약" 표시)
- `lane`: 표시할 줄 (각 타임라인의 `lanes` 참고)
- 구약의 `periods`는 '시대' 줄, `prologue`는 연대 미상 구간에 순서대로 놓입니다
- `link: "nt:jesus-born"`: 다른 타임라인의 항목으로 이동하는 버튼

연대는 보수적 전통 연대(출애굽 BC 1446, 왕상 6:1 기준)를 따르며, 학자에 따라 차이가 있습니다.

## 성경 밖 자료로 확인된 내용

[`js/evidence.js`](js/evidence.js)에 항목별로 고고학 발견·당대 비문·고대 문헌 증거를 적습니다.
해당 항목에는 타임라인에 ✓ 표시가 붙고, 상세 패널에 "이전 견해 → 확인" 형식으로 보입니다.
학계에서 널리 인정되는 자료만 넣고, 진위·해석 논란이 큰 자료는 넣지 않습니다.

```js
"pilate": [{ title: "빌라도 비문", year: "1961년 발견 (가이사랴)", doubt: "발견 전의 회의적 견해(선택)", text: "확인된 내용" }]
```

## 진행 중인 연구 (미확인)

[`js/research.js`](js/research.js)에는 아직 확인되지 않은 조사·논쟁 중인 주장을 따로 적습니다
(예: 두루프나르 '노아의 방주' 지형 시추, 여리고 성벽 연대 논쟁, 토리노 수의 연대).
해당 항목에는 주황색 ○ 표시가 붙고, 상세 패널에서 확인된 증거(✓)와 구분된 점선 상자에
상태(진행 중·논쟁 중·가설·논문 철회 등), 내용, 현재 평가가 함께 보입니다.
기준 시점은 `TIMELINE_RESEARCH_DATE`(현재 2026년 10월)이며, 내용을 갱신할 때 함께 바꿉니다.

