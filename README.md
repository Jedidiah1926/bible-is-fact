# 성경 타임라인 (bible-is-fact)

구약과 신약의 사건·인물을 연대순으로 살펴보는 인터랙티브 웹 타임라인입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다 (GitHub Pages로 그대로 배포 가능).

## 구성

- **구약** — 한 줄 타임라인
  - 위쪽 띠: 시대 구분 (족장 시대 → 이집트 체류 → 광야 → 사사 → 통일 왕국 → 북이스라엘/남유다 → 포로기 → 귀환 → 중간기)
  - 가운데 선 위의 점: 사건·인물 (라벨은 겹치지 않게 아래로 쌓임)
  - 왼쪽 상자: 연대를 특정할 수 없는 원역사 (창 1–11장)
- **신약** — 여러 줄(레인) 타임라인으로 같은 시기를 나란히 비교
  - 로마 황제 / 유대 통치자 / 예수 그리스도 / 사도·초대교회 / 바울 / 신약 기록 / 유대·로마 사건

## 사용법

| 동작 | 방법 |
| --- | --- |
| 이동 | 마우스 드래그, 스크롤, 터치 스와이프 |
| 확대·축소 | `Ctrl`(⌘)+휠, 트랙패드 핀치, 두 손가락 핀치, `+` / `-` 키, 상단 버튼 |
| 항목 보기 | 클릭 → 오른쪽(모바일은 아래) 패널에 설명·성경 구절·**같은 시기** 항목 목록 |
| 같은 시기 | 항목을 선택하면 세로 기준선이 생기고 같은 시기 항목만 강조됨 |
| 이전/다음 | `←` `→` 키 또는 패널의 버튼 |
| 검색 | 상단 검색창 (`/` 키), `Enter`로 결과 사이 이동 |
| 필터 | 범례 칩을 눌러 분류/레인 숨기기·보이기 |
| 공유 | 주소가 `#nt/council` 처럼 바뀌므로 그대로 링크 공유 가능 |

## 데이터 수정

모든 내용은 [`js/data.js`](js/data.js)에 있습니다.

```js
{ id: "exodus", start: -1446, cat: "event", title: "열 재앙과 출애굽", ref: "출 7–14장", desc: "..." }
{ id: "journey1", lane: "paul", start: 47, end: 48.5, approx: true, title: "1차 전도여행", ref: "행 13–14장", desc: "..." }
```

- `start` / `end`: 연도 (음수 = 기원전). `end`가 있으면 기간 막대, 없으면 점으로 표시
- `approx: true`: 추정 연대 (속이 빈 점, 점선 막대, "약" 표시)
- 구약은 `cat`(분류), 신약은 `lane`(줄)을 지정
- `link: "nt:jesus-born"`: 다른 타임라인의 항목으로 이동하는 버튼

연대는 보수적 전통 연대(출애굽 BC 1446, 왕상 6:1 기준)를 따르며, 학자에 따라 차이가 있습니다.
